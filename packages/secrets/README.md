# @claudexor/secrets

Internal package of [Claudexor](https://github.com/razzant/claudexor) — File-only 0600 managed-secret store; named secret refs resolved by adapters while vendor-native credentials remain vendor-owned.

Published as part of the Claudexor toolchain; it follows the monorepo's
lockstep version and has no separate semver contract. Use the `claudexor`
CLI (or `@claudexor/cli`) as the supported entry point.
